# Reference material

Local copies of the public domain plans, photographs and research notes used to build the model.

Everything in this folder except this file is ignored by git. The record of what each file is, where it came from, its licence status and where it is used lives in [`docs/SOURCES.md`](../docs/SOURCES.md), which is committed. To rebuild this folder, download each file from the link given there and save it under the path shown.

Rules for this folder:

- Public domain or CC0 only. Check the licence statement on the hosting page yourself and quote it in the log.
- Log a file in `docs/SOURCES.md` before using it.
- One folder per wreck (`titanic/`), then one per topic (`as-built/`, `wreck-site/`).
